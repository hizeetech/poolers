Upload Excel File

The importer auto-detects which of the two formats below you are uploading (based on column headers and total column count). Both formats share columns A–D (Serial / Home / Ignored / Away).

Format 1 — Draw Only (legacy, 7 columns A–G)

  • Column A: Serial Number
  • Column B: Home Team
  • Column C: (Ignored, e.g. “vs”)
  • Column D: Away Team
  • Column E: Draw Odd
  • Column F: Match Date (dd/mm/yy)
  • Column G: Match Time (HH:MM)

Format 2 — Complete 1X2 + Double Chance (12 columns A–L)

  • Column A: Serial Number
  • Column B: Home Team
  • Column C: (Ignored, e.g. “vs”)
  • Column D: Away Team
  • Column E: Home Win Odd (1)
  • Column F: Draw Odd (X)
  • Column G: Away Win Odd (2)
  • Column H: Home or Draw (1X)
  • Column I: Either Team Win (12)
  • Column J: Away or Draw (X2)
  • Column K: Match Date (dd/mm/yy)
  • Column L: Match Time (HH:MM)

Header row tips: Friendly labels like “Home Win Odd”, “1X”, “Either Team Win (12)”, “Match Date” are recognised automatically. If no header labels are present, the importer falls back to the positional layouts above.
